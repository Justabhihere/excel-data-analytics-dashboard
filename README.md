## 🚀 Deployment

The application is deployed using **Netlify**.

### Deployment Steps

1. Push the project code to GitHub.
2. Log in to Netlify.
3. Select **Add new project → Import an existing project**.
4. Connect the GitHub repository.
5. Select the repository.
6. Configure the build settings if required.
7. Deploy the project.
8. Verify the generated public URL.
9. Test the deployed application again.
